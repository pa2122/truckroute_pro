**TruckRoute Pro** is a next-generation, standalone commercial truck navigation application powered by Google Maps' **Large Vehicle Routing (LVR)** engine.

---

## 🌟 Key Features

- 🚛 **Custom Vehicle Dimensions Profile** (Height: 13'6", Weight: 80,000 lbs, Width: 102", Length: 53ft, Axle Count: 5).
- 🗺️ **Google Large Vehicle Routing Engine**: Calculates truck-legal safe routes avoiding low bridges, weight limits, and non-truck roads.
- ⛽ **Truck Stops & Diesel Stations**: Integrated Love's, Pilot Flying J, TA/Petro locations along route.
- ⚖️ **Scale Houses & Weigh Stations**: Real-time weigh station and rest area markers.
- 💳 **In-App Subscription ($9.99/mo)**: Google Play Billing Client integration.
